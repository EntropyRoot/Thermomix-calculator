# 🧮 tcalc

**ماشین‌حساب پیشرفته، سبک و فوق‌سریع ترمینال برای Termux — با زبان C خالص**

`C11` · بدون وابستگی (حتی بدون ncurses) · حدود ۲۰۰ کیلوبایت · اجرا در چند میلی‌ثانیه

</div>

---

`tcalc` یک ماشین‌حساب علمی، مهندسی و برنامه‌نویسی با **رابط متنی تمام‌صفحه (TUI)** است که مخصوص
گوشی‌های اندروید و **Termux** طراحی شده، ولی روی هر لینوکس، macOS و WSL هم کار می‌کند.
تمام برنامه با C استاندارد نوشته شده و فقط به `libc` و `libm` نیاز دارد.

```
 tcalc                           DEG  DEC  AUTO
 2sin(30) + sqrt 16                         = 5
 f(x) = x^2 + 1                         defined
 f(12)                                    = 145
 integ(exp(-x^2), x, -inf, inf)
                             = 1.77245385090552
 solve(x^3 = 2x + 5, x)      = 2.09455148154233
 conv(100, km, mi)           = 62.1371192237334
 :factor 360              360 = 2^3 × 3^2 × 5
 0.75                                    = 0.75
──────────────────────────────── Tab ↑↓ :help ──
» deriv(x^3, x, 2)
 = 12   0xC  0b1100
```

## ✨ ویژگی‌ها

**رابط کاربری (TUI)**
- تاریخچهٔ محاسبات با اسکرول، و **پیش‌نمایش زندهٔ نتیجه** همزمان با تایپ
- رنگ‌آمیزی نحوی (اعداد، توابع، متغیرها، ثابت‌ها) و نمایش پرانتز جفت
- **بستن خودکار پرانتزها**: `sqrt(2` همان `sqrt(2)` است (پرانتزهای باقی‌مانده کم‌رنگ نمایش داده می‌شوند)
- تکمیل خودکار نام‌ها با <kbd>Tab</kbd>، جستجوی تاریخچه با <kbd>↑</kbd> <kbd>↓</kbd> (بر اساس متن تایپ‌شده)
- ویرایش کامل خط: Undo/Redo، حذف کلمه، پرش بین کلمات، چسباندن (paste) امن
- **پشتیبانی لمسی/ماوس**: ضربه روی یک نتیجه ⇐ درج در ورودی؛ ضربه روی `DEG`/`DEC`/`AUTO` ⇐ تغییر حالت؛ کشیدن ⇐ اسکرول
- سازگار با صفحهٔ کوچک گوشی (حتی ۲۰ ستون) و در صفحهٔ عریض پنل کناری متغیرها و توابع
- با تایپ عملگر در خط خالی، محاسبه از نتیجهٔ قبلی ادامه پیدا می‌کند (`*2` ⇐ `ans*2`)
- قطع محاسبهٔ طولانی با <kbd>Ctrl</kbd>+<kbd>C</kbd> بدون بستن برنامه
- ذخیرهٔ خودکار تاریخچه، متغیرها، توابع و تنظیمات بین اجراها

**موتور محاسبه**
- پارسر Pratt با تا شدن ثابت‌ها (constant folding) و اجرای درخت بهینه، بدون هیچ تخصیص حافظه در حین محاسبه
- **ضرب ضمنی**: `2x`، `2pi`، `3(4+5)`، `(1+2)(3+4)`، `pi r^2`
- بیش از **۱۰۰ تابع داخلی**: مثلثاتی، هذلولوی، لگاریتم و ریشه، گرد کردن، نظریهٔ اعداد، آمار، توزیع نرمال، اعداد تصادفی
- حالت زاویه DEG / RAD / GRAD با مقادیر **دقیق** (`sin(180) = 0` و نه `1.2e-16`، `tan(90)` تعریف‌نشده)
- **حسابان**: انتگرال معین (Gauss–Kronrod تطبیقی، حتی با حدود بی‌نهایت)، مشتق عددی تا مرتبهٔ ۴ (روش Ridders)، حل معادله (Newton + Brent)، سیگما و حاصل‌ضرب
- متغیرها و **توابع کاربر** (با پشتیبانی بازگشت)
- **حالت برنامه‌نویس**: نمایش در مبنای ۱۶/۲/۸، اعداد `0xFF` `0b1010` `0o17`، عملگرهای بیتی، `xor`، شیفت
- **تبدیل واحد**: بیش از ۱۰۰ واحد در ۱۴ دسته (طول، جرم، دما، حجم، داده، فشار، انرژی، ...)
- **رسم نمودار** در ترمینال با کاراکترهای بریل (هر خانه ۲×۴ نقطه)، تا ۶ تابع رنگی، زوم، جابه‌جایی و ردیابی مقدار
- نمایش کسر و شکل نمادین نتیجه: `0.75 ⇐ 3/4`، `1.5707… ⇐ π/2`، `0.7071… ⇐ √2/2`
- تجزیه به عوامل اول (Pollard rho) و تست اول بودن قطعی (Miller–Rabin)
- **ورودی ارقام فارسی و نمادهای کیبورد گوشی**: `۱۲ × ۳ + ۴٫۵`، `÷`، `−`، `π`، `√`، `²`، `°`
- حالت خط فرمان و pipe برای اسکریپت‌نویسی

## 📲 نصب در Termux (اندروید)

۱. **Termux** را از [F-Droid](https://f-droid.org/packages/com.termux/) یا
[GitHub](https://github.com/termux/termux-app/releases) نصب کنید
(نسخهٔ Google Play قدیمی است).

۲. دستورهای زیر را در Termux اجرا کنید:

```bash
# به‌روزرسانی بسته‌ها
pkg update && pkg upgrade -y

# نصب کامپایلر، make و git
pkg install -y clang make git

# دریافت سورس
git clone https://github.com/EntropyRoot/Thermomix-calculator.git
cd Thermomix-calculator

# کامپایل
make

# (اختیاری) اجرای تست‌ها
make test

# نصب در $PREFIX/bin تا از هر جایی با دستور tcalc اجرا شود
make install

# اجرا
tcalc
```

> در Termux متغیر `PREFIX` از قبل تنظیم شده است، پس `make install` برنامه را بدون نیاز به
> `sudo` در مسیر `$PREFIX/bin` (یعنی `/data/data/com.termux/files/usr/bin`) کپی می‌کند.

بدون نصب هم می‌توانید از داخل پوشهٔ پروژه اجرا کنید:

```bash
./tcalc
```

### به‌روزرسانی و حذف

```bash
cd Thermomix-calculator
git pull && make && make install   # به‌روزرسانی
make uninstall                     # حذف برنامه
```

## 🛠️ کامپایل

### با make

| دستور | کار |
|---|---|
| `make` | ساخت نسخهٔ بهینه (`-O2`) ⇐ فایل `./tcalc` |
| `make native` | ساخت با `-O3 -march=native` برای همین پردازنده (سریع‌ترین حالت) |
| `make debug` | ساخت با `-O0 -g` و AddressSanitizer/UBSan برای اشکال‌زدایی |
| `make test` | اجرای مجموعهٔ تست‌ها |
| `make install` | نصب در `$(PREFIX)/bin` |
| `make uninstall` | حذف از `$(PREFIX)/bin` |
| `make clean` | پاک کردن فایل‌های ساخته‌شده |

می‌توانید کامپایلر و پرچم‌ها را عوض کنید:

```bash
make CC=gcc
make OPT="-O3 -mcpu=native"      # اگر کامپایلر شما -march=native را نشناخت
make PREFIX=$HOME/.local install # نصب در مسیر دلخواه
```

### کامپایل دستی (بدون make)

تمام پروژه با یک دستور کامپایل می‌شود:

```bash
clang -O2 -o tcalc src/*.c -lm
```

یا با gcc:

```bash
gcc -O2 -o tcalc src/*.c -lm
```

بیشترین بهینه‌سازی برای پردازندهٔ همین دستگاه:

```bash
clang -O3 -march=native -o tcalc src/*.c -lm
```

### لینوکس، macOS و WSL

```bash
# Debian / Ubuntu
sudo apt install build-essential git
# Fedora:  sudo dnf install gcc make git
# macOS:   xcode-select --install

git clone https://github.com/EntropyRoot/Thermomix-calculator.git
cd Thermomix-calculator
make && sudo make install
```

## ▶️ اجرا

| دستور | توضیح |
|---|---|
| `tcalc` | رابط تمام‌صفحه (TUI) |
| `tcalc '2^10 + sqrt(16)'` | محاسبه و چاپ نتیجه ⇐ `1028` |
| `tcalc -r 'sin(pi/6)'` | با حالت رادیان ⇐ `0.5` |
| `tcalc -x '255 + 1'` | خروجی هگز ⇐ `0x100` |
| `echo 'conv(5, km, mi)' \| tcalc` | خواندن از ورودی استاندارد ⇐ `3.10685596118667` |
| `tcalc ':plot sin(x); cos(x)'` | رسم نمودار در خروجی ترمینال |
| `tcalc --plain` | حالت سادهٔ خط به خط (بدون TUI) |

> ⚠️ در شل حتماً عبارت را داخل `'...'` بگذارید، چون شل نویسه‌هایی مثل `( ) * ^` را خودش تفسیر می‌کند.

چند خط پشت سر هم (مناسب اسکریپت):

```bash
printf 'r = 3\npi r^2\n' | tcalc        # 28.2743338823081
tcalc -e 'x = 7' -e 'x^2 + 1'           # 50
```

| گزینه | توضیح |
|---|---|
| `-e EXPR` | محاسبهٔ عبارت (قابل تکرار) |

| `-p N` | تعداد ارقام معنادار (۱ تا ۱۷، پیش‌فرض ۱۵) |

| `--no-color` | بدون رنگ (متغیر محیطی `NO_COLOR` هم پشتیبانی می‌شود) |
| `--no-mouse` | غیرفعال کردن ماوس/لمس |
| `-h`, `-v` | راهنما / نسخه |

کد خروج در حالت خط فرمان: `0` موفق، `1` خطای محاسبه، `2` گزینهٔ نامعتبر.

|---|---|

### متغیرها و توابع کاربر

```text
x = 5
r = sqrt(x^2 + 1)
x += 2
f(x) = x^2 + 1
area(r) = pi r^2
g(a, b) = hypot(a, b)
f(3) + g(3, 4)                          = 15
fact2(n) = if(n <= 1, 1, n * fact2(n - 1))
fact2(10)                               = 3628800
a = 2; b = 3; a * b                     = 6
```

متغیرها و توابع هنگام خروج ذخیره می‌شوند و دفعهٔ بعد در دسترس‌اند.

### حسابان

```text
sigma(k^2, k, 1, 10)                    = 385
product(k, k, 1, 5)                     = 120
integ(x^2, x, 0, 3)                     = 9

deriv(x^3, x, 2)                        = 12

solve(cos(x) - x, x, 0, 1)              (جستجو در بازهٔ [0, 1])

```

## 📱 نکته‌های Termux

**کلیدهای اضافه:** برای دسترسی راحت به Tab، Ctrl و کلیدهای F، فایل `~/.termux/termux.properties` را
ویرایش کنید:

```properties
extra-keys = [['ESC','TAB','CTRL','ALT','LEFT','DOWN','UP','RIGHT'], \
              ['F1','F2','F3','F4','F5','PGUP','PGDN','DEL']]
```

سپس دستور `termux-reload-settings` را اجرا کنید. (در Termux ترکیب دکمهٔ «افزایش صدا» با اعداد
<kbd>1</kbd> تا <kbd>9</kbd> هم کلیدهای F1 تا F9 را می‌فرستد.)

**لمس:** روی هر نتیجه در تاریخچه ضربه بزنید تا در ورودی درج شود؛ روی `DEG`، `DEC` یا `AUTO` در نوار
بالا ضربه بزنید تا حالت عوض شود؛ برای اسکرول، صفحه را بکشید. اگر انتخاب متن با لمس طولانی را ترجیح
می‌دهید، با `:mouse off` یا `tcalc --no-mouse` لمس را خاموش کنید.

**چرا رابط برنامه انگلیسی است؟** ترمینال Termux از متن راست‌به‌چپ و اتصال حروف فارسی پشتیبانی
درستی ندارد و متن فارسی در آن به‌هم‌ریخته نمایش داده می‌شود؛ برای همین متن‌های داخل برنامه انگلیسی
هستند. ولی **ورودی ارقام فارسی و عربی** (`۰-۹`، `٠-٩`، ممیز `٫`) و نمادهای کیبورد گوشی
(`× ÷ − π √ ² ³ °`) کاملاً پشتیبانی می‌شوند.

| فایل | کاربرد |
|---|---|
| `~/.tcalcrc` | اسکریپت شروع شما (هر بار اجرا خوانده می‌شود، برنامه هرگز آن را تغییر نمی‌دهد) |

# ثابت‌ها و توابع شخصی

## 🧩 ساختار پروژه

```text
src/
├── calc.h       تعریف‌های مشترک
├── lexer.c      توکنایزر + تبدیل ارقام فارسی و نمادهای یونیکد
├── parser.c     پارسر Pratt، جدول نمادها، constant folding
├── eval.c       اجرای درخت عبارت، انتگرال، مشتق، حل معادله
├── builtins.c   توابع داخلی، اعداد اول، تجزیه
├── format.c     قالب‌بندی اعداد، مبناها، کسر و شکل نمادین
├── units.c      جدول تبدیل واحدها
├── commands.c   دستورات :، راهنما، ذخیره و بازیابی جلسه
├── term.c/.h    ترمینال خام، خواندن کلیدها/ماوس، رندر با diff خطی
├── tui.c        رابط تمام‌صفحه
├── plot.c       رسم نمودار با بریل
└── main.c       خط فرمان
tests/run_tests.sh   تست‌ها (make test)
```

**چرا سریع است؟** عبارت‌ها یک بار پارس و به درخت فشرده تبدیل می‌شوند، ثابت‌ها همان موقع محاسبه
می‌شوند، نام متغیرها و توابع هنگام پارس به اشاره‌گر تبدیل می‌شوند (بدون جستجو در زمان اجرا)، حافظهٔ
درخت از یک arena گرفته می‌شود و فریم‌های توابع روی یک پشتهٔ ثابت قرار می‌گیرند. رابط کاربری فقط
خطوط تغییرکرده را دوباره می‌کشد و هر فریم را با یک `write` می‌فرستد. روی یک پردازندهٔ دسکتاپ، اجرای
کامل برنامه برای یک عبارت حدود ۲ میلی‌ثانیه و هر فراخوانی تابع کاربر حدود ۵۰ نانوثانیه طول می‌کشد.
